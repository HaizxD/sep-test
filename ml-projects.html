PROJECT NOTES

Measure before
you celebrate.

A working demo is only one part of an ML project. Keep the test data separate, compare against a baseline, inspect errors and record limitations.

AIS project rule: write down what "good enough" means before training. This makes your evaluation less dependent on whether a single demo looks impressive.
